# Juego 3D de Recolección y Combate

## Descripción

Este proyecto corresponde al desarrollo de un videojuego 3D realizado en Unity. El objetivo del jugador es explorar el escenario, recolectar monedas, derrotar enemigos y vencer al jefe final para obtener una llave que permita completar el nivel.

## Características Implementadas

- Movimiento del jugador.
- Sistema de salto.
- Sistema de salud del jugador.
- Enemigos con inteligencia artificial mediante NavMesh.
- Sistema de daño de enemigos.
- Recolección de monedas.
- Jefe final con recompensa especial.
- Aparición de una llave al derrotar al jefe.
- Mensaje de "Nivel Terminado" al recoger la llave.
- Interfaz gráfica con indicadores de vida, monedas y llave obtenida.

## Controles

| Acción | Tecla |
|----------|----------|
| Moverse | WASD |
| Saltar | Espacio |
| Disparar | Clic Izquierdo |

## Requisitos

- Sistema operativo: Windows 10 o superior.
- Procesador y memoria compatibles con Unity.
- Resolución recomendada: 1920x1080.

## Motor de Desarrollo

- Unity Editor 6000.3.18f1

## Ejecución

1. Descomprimir el archivo entregado.
2. Ejecutar el archivo `.exe`.
3. Jugar y completar el nivel derrotando al jefe y obteniendo la llave.
